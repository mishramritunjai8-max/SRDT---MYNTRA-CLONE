# Myntra-style Fashion Store

A small frontend practice project made with HTML, CSS and basic JavaScript.

## Files
- `index.html` - page structure and content
- `style.css` - layout, colours and responsive styling
- `script.js` - add-to-bag counter, product search and newsletter message

## How to run
1. Extract this ZIP file.
2. Open the `myntra_clone` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Notes
- This is a student practice project inspired by fashion shopping websites. It is not the official Myntra website.
- Product images are loaded from Unsplash, so an internet connection is needed for those images.
- The bag counter and newsletter message are frontend demonstrations only. There is no payment, login, database or real email subscription system.
